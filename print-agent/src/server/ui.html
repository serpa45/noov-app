1. Conta da loja

Use o mesmo e-mail e senha que você usa para entrar no painel do NOOV.

2. Impressoras

O balcão recebe o cupom completo do cliente e a cozinha recebe a comanda enxuta. Você pode apontar as duas para a mesma impressora, ou desligar a que não tiver.

3. Comportamento

Depois de salvar, desative a impressão via QZ em Configurações → Impressora no painel, para o navegador não tentar imprimir em paralelo.

Registro de atividade

As últimas linhas do que o agente fez. É por aqui que se descobre por que algo não imprimiu.
